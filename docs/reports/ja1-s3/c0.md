# JA-1 S3 C0

C0 adds production Studio import/capture completion through the existing project owner, pins and ledger. Admission binds the complete source SHA-256/length, canonical stream/timebase/origin/colour interpretation, and an owned 1 MiB chunk table. Historical same-ID inputs, colour overrides, table dependencies and exact LUT/font resources survive copy, Save As, rescue and FirstSave. Duplicate publication hashes the existing object before discarding the incoming copy.

Certified media ports probe, decode, seek and reopen pinned descriptors. Independent four-slot cursors publish verified private bytes, check size on every callback, and latch failures through buffered output. Cursor, AVIO, decoder/frame and resource reservations precede allocation on the same ledger. Nested opens are restricted by protocol/format policy and callback refusal; incomplete/dynamic or non-A/V stream tables refuse before probe, and new streams cannot exceed the pre-reserved count. See the [pinned FFmpeg audit](evidence/media-ffmpeg8-avio-audit.md).

Host/App input admission refreshes the existing manual encoder and lease. Studio incident colour recovery preserves an open incident until the existing staged Media Bin action is used. PF1/SourceSpec/audio-mixer integration remains C2; C0 does not close G7-S/G8 or add C1 role credentials.
