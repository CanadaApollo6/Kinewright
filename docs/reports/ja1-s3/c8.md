# JA-1 S3 C8 host voice notes

C8 supplies `Ja1EditingSession` voice ports and authenticated host capture, receipt, transcription, status, transcript choice and selected audio-range commands. Studio controls and snapshot read leases follow in C9.

`AcknowledgeVoice` streams WAV then playhead-log bytes outside the metadata envelope. Its reservation survives through SaveVoice publication. Both complete streams, digests, duration and every logged snapshot/frame are checked before admitting objects. Oversize and truncation leave no object or reservation. C5's per-note slot remains the only SaveVoice publisher; acknowledgment means its receipt committed.

Recovery looks up the exact original receipt first. Committed acknowledges without re-issue. Absent permits the same note and capture bytes under a fresh current-epoch envelope. No epoch bypass or host pending-capture store is added. The App retains its capture until acknowledgment.

Whisper runs in the host because the bundle owner must retain the completion carrier and retry C5 acceptance/publication on Unsettled. Asset and note inference share one process-wide model-lifetime mutex; contexts drop before unlocking. Note workers retain audio read charges and reserve 2 GiB for native model/workspace/PCM overlap. Missing models give a plain saved-audio reason; provisioning uses only pinned, hash-checked `ensure_model`.

Private range reads authorize like SaveFeedback, deny Producers, round sample boundaries inward and refuse intervals outside the immutable revision's range. Original ASR and chosen text remain separate.
