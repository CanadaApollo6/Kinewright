# JA-1 S3 C3

C3 adds typed and drawn comments in `kinewright-app/src/studio_feedback.rs`, with the host feedback adapter.

- **Capture** reads only the bound display cell, never the pending selection or seek. It records the version, or the exact manual cut, plus the frame, rational fps, raster, orientation, text and strokes. Strokes are normalised against the displayed image rectangle after letterboxing. The target stays unresolved until the person picks a layer. Source and beat stay absent.
- **Frame proof** carries the bound cell identity. On the CPU route it also carries a SHA-256 of that cell's own pixels, hashed on a thread that owns the image it started on.
- **Manual-edit drafts** are promoted only when a published snapshot's checkpoint history has the identical document and journal position. A newer head never promotes them, even after an undo back to the same document.
- **Save** clears a draft only on a durable receipt that the index retains. A refusal or an unknown outcome keeps the draft, and the retry resends the exact original command.
- **Revise cut** sends a batch of exact revisions, which can mix versions. A retry resends the original batch whatever the selection became. With no scheduler attached, the state reads "Submitted · waiting for a run".
- **Edits** to a saved note create a new revision with the original anchor and proof reference.
- **Caps** refuse at ingress and keep the draft: 2,000 comments, 16 KiB of text, 512 points.
- **Host commands.** `AdmitFeedbackEvidence` stores bounded evidence. `ListFeedback` returns the private index. The Producer role is refused both.

## Witnesses and mutation pairs

The two witnesses are `s3_displayed_packet_and_letterbox` and `s3_batch_revision_and_lost_reply`. The agent test `s3_feedback_adapter_is_private_until_batch` covers role refusal, the caps, and that agents see no batch before submission.

Each guard has one runtime red/restored-green pair, rerunning only its witness:

| Guard | Mutation | Red at |
| --- | --- | --- |
| Bound-cell identity | Capture uses the pending selection and seek | `C3_CAPTURE_BOUND` |
| Exact pending-cut acknowledgment | Any later journal position acknowledges | `C3_NEWER_HEAD_NEVER_PROMOTES` |
| Original-revision retention | A retry rebuilds the batch from the current selection | `C3_ORIGINAL_BATCH_RETRIED` |
| Durable draft-clear guard | An unknown outcome clears the draft | `C3_LOST_SAVE` |
