## Result and authority

The host prepares, pins and publishes through the existing local Save/select implementation. It validates the old project, branch, owner epoch, head, checkpoint reference/generation, floor generation, switch generation, revision and issuer sequence. The ordinary Save publishes dirty source history first; the selection root retains that saved branch, creates one adopted branch or selects an existing BranchId, advances switch generation and records the original-envelope Switch receipt in that same transaction. Adoption does not append a whole-document Undo entry. Snapshot identity is a supplied VersionId fixture; this adds no S3 VersionIndex producer.

The rich result references the actual committed old and new checkpoints, history, inputs and lineage. Independent Open and the candidate-root guard check those checkpoint objects and require `host-switch@1`. The optional envelope field is omitted for legacy edit/comment encodings. Receipt lookup returns the original result plus the current committed pointer when superseded; it never confers a lease or repeats historical selection.

The GUI stages the target actor, subscription and resources before publication. Both producers remain frozen until the installed current pointer and digests match the committed attachment; confirmation then grants fresh authority. Retry retains the original envelope. Definite prepublication failure revalidates the saved old history under a fresh lease; unknown publication freezes both. Cold reopen restores the actual subscribed App view. A delayed old stamped lease refuses even after return to the same BranchId. Existing Undo/Redo, occurrence/batch identities, resource inputs and the protected acknowledged recovery remain covered by runtime witnesses.

The same complete-closure target pin survives preliminary Save, quota/retirement, slot rotation, collection and retry. Real host create/reopen routes retain `Ja1EditingSession` registration guards. The retirement witness creates distinguishable unsaved session history and attempts removal before checking blocker disclosures; base dependency retirement is independently attempted. Failed/unknown frozen rescue never resumes the source. Successful B handoff irrevocably abandons the wrapped selection, and late A reconciliation does not replace B. The accepted original session-pin crash-window limitation remains; this commit does not add durable pin recovery.
