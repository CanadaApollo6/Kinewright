## Ownership and command behavior

- `crates/kinewright-project/src/source_boundary.rs:18`, `crates/kinewright-project/src/bundle_copy.rs:54`: borrowed host descriptors carry
  verified bounded reads and no source cleanup/release authority. Reader leases retain
  the actual GUI hold and reservation; exact snapshot growth charges a checked delta
  on that same ledger, including metadata scratch admission.
- `crates/kinewright-project/src/store.rs:206`, `crates/kinewright-project/src/namespace/linux.rs:1162`: explicit Close fences new reads and waits
  for outstanding readers. Failed cleanup remains charged and retryable. A retry after
  a successful unlink cannot delete a successor directory that reused the name.
- `crates/kinewright-project/src/editing_session.rs:239`, `crates/kinewright-project/src/editing_session/recovery.rs:19`: floor installation and
  preliminary Save/reconcile replies use the actual publisher history/head and surviving
  L identity. They do not substitute a later live Core read. Ordinary floors keep the
  actor; committed recovery/rescue activation creates a fresh actor.
- `crates/kinewright-agent/src/writer_host/mod.rs:1078`: private bootstrap validates the exact frozen GUI snapshot,
  size/hash and source overlap before serving sessions. Unsaved edits and Redo seed
  the host shadow without publishing or marking them Saved. Named handover retains
  the old actual Saved digest while installing unsaved history.
- `crates/kinewright-agent/src/writer_host/auth.rs:15`, `crates/kinewright-agent/src/writer_host/protocol.rs:15`: 256-bit OS-random bearer authentication, project and
  protocol checks precede reads/body execution. Discovery contains no credential.
  Launch uses private stdin; stdio proxy stdout carries protocol only. Source services
  permit only Prove/Read/Inspect/SnapshotProof and one exact host instance claim.
- Host publication is serialized through `HostCommandOwner`; host-owned sessions reuse
  the existing pump and survive GUI chat detach. Native destination capabilities pin
  existing ancestors and walk without following links. Person-picked external paths
  require exact private destination grants and narrowed forwarded scope. Source and
  destination namespaces stay separate. Non-Linux Studio mutation remains unsupported.
- `crates/kinewright-app/src/ja1_attachment.rs:302`, `crates/kinewright-app/src/ja1_host.rs:287`: GUI Action gates permanently fence lost
  retention while preserving edits/data until explicit Close. Close waits/reaps its
  owned child, with a bounded owned-child fallback; detach does not cancel host sessions.

## Integration details, deviations and limitations

- `crates/kinewright-agent/src/writer_host/auth.rs:66`: root headers encode Unicode as ASCII JSON (including UTF-16
  surrogate pairs), and escape `$` so a literal path cannot expand a child environment
  variable. Serde round-trips the exact path. Real stdio/session fixtures use Japanese
  and emoji directories. The configuration-only Claude witness uses the documented
  [environment-variable header expansion](https://code.claude.com/docs/en/mcp#environment-variable-expansion-in-mcp-json):
  full bearer stays in the child environment; argv contains only its literal reference.
  Debug is redacted. This does not establish actual provider compatibility.
- `crates/kinewright-agent/src/server.rs:1316`: host-scoped file/media operations without a native pinned
  capability refuse `root_refused` before dispatch; no unpinned filesystem path is
  forwarded through the session. This limits current host media functionality and is
  disclosed rather than treating the old string roots as a native capability.
- `crates/kinewright-agent/src/acp_session.rs:318`: protected connectors without authenticated inline MCP headers
  refuse explicitly. Authentication is never silently dropped. Actual providers remain
  a later acceptance lane.
- `crates/kinewright-agent/src/writer_host/protocol.rs:15`: explicit snapshot payloads use the existing 32 MiB history bound and
  a 40 MiB wire allowance; ordinary commands are bounded to 256 KiB, source chunks
  to 64 KiB. Exact grants (32), roots (64), pins (64), sessions (16), ancestry (32)
  and in-flight ingress (64) are bounded and refuse at the limit.
- `crates/kinewright-agent/src/writer_host/mod.rs:1078`: the exact initial bootstrap and foreground Save snapshot
  are C8 initialization/publication inputs. There is no continuous manual stream or
  recovery barrier, and no claim that C9/C10 ordering is implemented.
- `crates/kinewright-project/src/editing_session.rs:615`: B is prepared/subscribed before A is sealed; preparation
  failure cleans up B. B resume may still fail after A is sealed, leaving both fenced
  and the context fail-closed. An infallible switch tail is not claimed. Original S2-R
  Opus r2 N2 at `editing_session/rescue.rs:293,318–323` remains deferred to C12;
  the added guard does not claim to repair that local rescue tail.
- Native path capabilities are Linux implementations with typed unsupported-profile
  refusals elsewhere. C8 does not add Windows Studio durable success. The portable
  transport uses standard TCP/process/pipe APIs and no new `cmd /c` quoting path.
- `SessionStore` cleanup now remembers successful unlink before a later sync error,
  so retry can retire accounting without touching a reused pathname. This is required
  to make explicit owner Close retryable without making host Drop an owner.
