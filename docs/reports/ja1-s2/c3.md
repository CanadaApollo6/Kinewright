# JA-1 S2 C3: lifecycle ownership and retained reads

C3 is based on C2 `e204c61` in `/home/riels/.t3/worktrees/Kinewright/t3-cf687318`,
branch `ja1/s2`. It adds the project-local lifecycle and read-only admission APIs.
Rescue publication, selection records, the App and the host remain later commits.

`Ja1EditingSession` owns the Core attachment, ordinary source and destination owners,
active association and rescue accounting. `save_headless_bundle` uses this owner.
An ordinary successful first-save handoff retires its unadopted temporary source under
the existing reader rules. An adopted source retains its original `BundleCopy`,
namespace, ancestor claim, Core, exact ticket, source bytes and charges until Close.
First-save continuation borrows the original writer. It never reacquires its own lock.
Committed and continuous absent outcomes use the existing exact-ticket commit or release.
Reconciliation does not update the Saved baseline or association.

`RetainedReadAdmission` owns a real `SourceCopyHold`, complete-closure pin and metadata
reservation. Each returned private `RetainedReadLease` keeps that same actual hold and a handle charge
alive until the reader closes, including after context Close. It accepts only admitted
ObjectRefs and verifies hashes and measured lengths
through pinned directories. An unsaved first-save capture uses the retained local source
manifest before destination bytes. It does not follow an external locator.
Missing-byte pages report exact references, retaining uses, causes, omitted counts and
dependency completeness. The diagnostic working set uses the existing storage accounting.

`RescueProbe` keeps phase, operation, tag, optional exact ticket and the original error.
Its cause table excludes interruption, contention, invalid operations, unsupported profiles,
cleanup-only uncertainty and known publication outcomes. Selection performs a second
serialized probe. Captures and consents bind the actor cut, input roots and exact attempt.
Cancel preserves a pre-existing freeze and consumes no rescue slot.

`DestinationInspection` pins the nearest existing ancestor without creating parents,
locks or stores. It excludes retained roots, assets, temporary storage and lost-parent
subtrees. Revalidation refuses changed ancestors. Namespace locks are deduplicated and
acquired in a stable order. Ordinary Save never consults the four-slot limit.

C3's adoption adapter is test-only. Its slot transitions model source adoption and
destination outcomes without publishing a rescue. Repeated real ordinary unknown attempts
at one A retain distinct source holds, tags, exact tickets and settlement status. Four-slot
ordinary-save controls run independently of rescue publication. C5 owns the complete
A to B to C rescue sequence and the actual first-mutation caller.

## Ownership and release

| Held object | Owner | Release |
| --- | --- | --- |
| Live Core and proof-bound attachment | `Ja1EditingSession` | Context Close; separately held Core clones follow their existing lifetime |
| Named bundle, namespace lock, store and durable graph pin | `RetainedDestination::Named` | Context Close under ordinary cleanup rules |
| First-save destination writer and `PreparedDestination` ancestor claim | `RetainedDestination::FirstSave` owning the original `BundleCopy` | Ordinary unadopted handoff, or context Close for an adopted source |
| Temporary source namespace and physical bytes | Original `SessionStore`, `BundleCopy` source hold and actual store pins | Ordinary unadopted handoff or adopted context Close, then last retained reader; uncertain cleanup keeps its existing charges |
| Ordinary pending save, exact barrier, tag and staged command state | Original `ProjectBundle` inside the retained destination | Only the same live attempt's proved settlement; sealed ticket remains to Close |
| Original copy's pin, overlap reservation and uncertainty | Original `SourceCopyHold` in `BundleCopy` | Adopted context Close; settlement clears only its uncertainty |
| Per-attempt actor, tag, exact ticket identity, capture and settlement status | Each `RetainedAttempt` | Context Close; distinct attempts never share a settlement flag |
| Closure pin and source overlap | Shared actual `SourceCopyHold` owned by `RetainedReadAdmission` and issued leases | Preview cancel or adopted context Close, then last issued reader |
| Reference-list metadata charge | `RetainedReadAdmission` in its charged capture | Preview cancel or adopted context Close |
| Issued file, shared actual source hold and handle charge | Private `RetainedReadLease` | Last issued reader, after context retirement allows cleanup |
| Decoded frozen history charge | `StorageReservation<FrozenRescueCapture>` | Preview cancel or adopted context Close |
| Read-only pinned candidate ancestor | `DestinationInspection` | Preview cancellation or completed admission; no writer is created by inspection |
| Consumed source and unknown-destination slots | `RescueSlots` in the originating session | Context Close; settlement never refunds a slot |

Unresolved cleanup retains its existing owner charges. A consumed source slot survives a
mutating definite destination refusal. Success and definite refusal return only the
destination reservation. These transitions are C3 accounting controls, not C5 publication.
