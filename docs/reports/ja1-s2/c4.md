## Scope and contracts

C4 adds `RescueCopyV1` as bounded OwnedEvidence, its dedicated R_ack edge, original-command
lookup and compaction, strict raw role/API admission, L1 restricted projection, B-owned
prepared restore, and frozen local selection through the shared BundleCommit. The selected
complete closure is pinned before any ordinary Save and resolved by verified SHA after
rotation. Existing targets keep their exact checkpoint/head. Refusal, unknown, retry,
committed diagnostics, pointer refresh, g preservation and first-R Save are exercised.
Ordinary branch/floor lineage retains shared batch and occurrence identities generally.

The L1 oracle independently opens fully rehashed graphs, compares the flattened Document,
exact branch/input/receipt/issuer references and independent evidence, and rejects valid
Document, batch and input payload changes. Projection changes only inherited rescue linkage
and necessary containers. Original input payloads retain their identity and bytes while
actual leases use B ownership/epoch; B-only reopening succeeds after A is removed.

- `docs/JA-S0-CONTRACTS.md:539`: binding revision-7 qualification and final L1 exception.
- `docs/JA-S0-AMENDMENT-A1.md:367`: matching A1 frozen-rescue and one-level retention qualification.

The contracts explicitly supersede P/exact-pre-floor/editable-paused rulings. C5 still owns
