Publication enumerates the candidate BranchIndex independently of either cache. Each exact
verified history hash has one resident charge, with the same current/archived checkpoint order,
encoded/hash-working/preflight/raw/typed/replay overlaps and physical closure accounting as Open.
The bounded memo stores costs, raw-support fields and dependency identities, keyed by the entire
ObjectRef and effective StorageLimits. It stores no decoded histories, persistent accounting or
reservations. Open/reconciliation fully verify and seed it; publication remembers objects already
decoded and verified in this session. A miss decodes/preflights exactly. Explicit re-verification
invalidates affected facts; namespace-continuity failure discards the memo. Traversal controls
are interpreted each time. This is incremental payload verification, not constant-cost saving.

reader after changed histories and cache misses, refuse wrong ObjectRef length/kind reuse, and
reverify after an actual namespace-identity failure. The original target-only witness keeps the
required publication-then-independent-open capacity failure; peak equality is checked in the
separate memo witness so it cannot mask that discriminator.
