## C4a: Agent adapters and host execution

The existing seven HTTP MCP tools discover and invoke the task controls. H3 checks role, task, attempt, endpoint, epoch, expiry, roots and candidate head before admitting a control or looking up its receipt. Assignment reserves dependency capacity before waiting. StartRun, work-turn boundaries and delivery offers remain host transitions. Scoped undo/redo validates the resulting document changes before updating the task actor.

Host startup restores retained inputs and run Producers, and reconciles the private native claim through `recover_run`. The host session constructs `EffectPump` and drives it through the existing `pump_session`, outside the serialized owner. Task profile binding uses the actual authenticated task MCP endpoint. The production path has no `ContainedDriver` fallback. Its registration remains empty, runtime qualification refuses by default, and production launch requires a positive token ceiling. Protocol fixture ports are Linux `test-util` only and cannot qualify installed providers.

Explicit Freeze ends the host-owned work turn and publishes its exact checkpoint and H1 history together. Repeated Freeze and merge retain their original history/receipt. A frozen task can be restored for merge after its native attempt is archived without buying another child send. Result templates name the current accounting record. Completed result publication leaves an executing native attempt able to drain raw usage; Ready is published only after cleanup proof. Late results cannot join an already charged wake, and a native turn is offered only the deliveries in its charged payload.

The MCP witness performs acknowledged edits and Undo, turn exit, another attempt, automatic host recovery, frozen-result publication and merge, then Stop and reopen. Exact task/manual `HistorySnapshot` values, their non-empty redo tails, the merge receipt and saved Director setting survive. A second production witness starts the host again before its first native attempt, edits over its real MCP endpoint, drains raw usage with unavailable cost, and retires one charged execution with proof. Stop is covered during blocked profile binding and while a still-executing child has filled all **30 ordinary-event slots**; the channel reserves two additional slots for terminal controls.
