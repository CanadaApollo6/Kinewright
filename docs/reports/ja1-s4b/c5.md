## C5a design and boundaries

Model the Domain separates product specifications from fixture execution specifications. `certified_connectors` and Director choices never include fixtures, including feature-unified builds. Explicit fixture hosts use a separate saved-choice reader and factory; product Settings rejects the fixture and preserves an old saved selection as unavailable. Atomic setting persistence tests use an explicit fixture registry. Release-feature-graph and unified assertions test the product registry. `c1.md` corrects the old feature-unification claim.

Boundary Discipline puts TCP rights in the final Landlock ruleset. `ProviderSandbox::LinuxAllowlist.connect_tcp` carries the port set through the immutable invocation and guardian. The native recipe grants 443 and the actual validated loopback MCP port. Landlock handles TCP bind and connect, grants connect only, and grants no bind. Landlock port rules constrain ports, not destination IP addresses. The MCP binding itself accepts loopback URLs only. UDP/DNS is not claimed to be restricted by these TCP rights.

Codex runtime trees derive from the canonical, identity-checked executable. An npm package tree is read-only; otherwise only the executable's own directory is added. A grant containing HOME is refused, and the existing native-identity overlap check refuses project/store authority. Protocol fixtures do not inherit that product runtime grant. The recipe writes its direct-tool `models-direct.json` from bounded local model metadata, rejects absent model choices and changed files, and uses no paid discovery. This is runtime support, not installed-provider qualification.

`recover_on_open` finishes an empty machine claim before asking an unsaved session for a locator. A retained foreign or durable attempt still requires the existing recovery proofs. N1 has an unsaved/no-claim witness.

`read_provider_output` is the common bounded reader for the native launcher and CI protocol children. Raw H1 accounting precedes legacy display parsing. Legacy Cost events are suppressed before entering the native event queue. The CI cases cover malformed/oversized frames, duplicate/cache/missing usage, auth failure, queued steering and interruption after one acknowledged H1 send. Children are killed/reaped on parser refusal. Their retirement uses the fixture's never-dispatched fence and certifies no native provider or cleanup proof.

The throughput checkpoint keeps shared edits serial. The final sandbox and registry boundaries are established first. Protocol and runtime tests then exercise those boundaries. One implementation owner avoids concurrent writes to the guardian recipe and host state.
