## C3a

The persisted-effect executor runs outside the serialized host and is driven by the existing Studio session pump. H1 reserves an attempt, persists its exact charge, and only then the guardian launcher can release it. Generic outbox claims and reconciled retries refuse ProcessBound effects. All opening, specialist, steering and coalesced-result sends share the same charge boundary. Wake payloads expand the result, explanation, delta, artifacts, evidence and usage before computing the charged hash; unsupported or oversized contents fail before charging.

StartRun publishes the six-hour clock in its first root cut. Elapsed time uses the larger of durable wall time and observed monotonic spending, includes waits and downtime, and pauses on a backward or untrusted clock. Task ledgers retain 80 sends across attempts, two repair rounds per delivery/attempt, repeated-failure replanning, rate-limit waits, provider selection and optional positive token ceilings. A ceiling can be provisioned only before the first provider admission and cannot be raised or reset. The ceiling stops subsequent sends; one provider turn may overshoot it. Missing usage blocks the next capped send. No numeric ceiling or qualified provider is silently selected.

The native reader records raw usage through H1 before the legacy parser can fill unavailable totals with zero. Attempt/turn/event identity deduplicates samples, cumulative totals replace rather than add, and cache/reasoning subsets are counted once. Missing tokens and cost stay unavailable. The aggregate effect session suppresses the legacy zero-filled Cost event; its spending authority is the durable raw ledger.

Recovery is an executor used after reopening the host and reacquiring the private machine claim. It never spawns or retries an unknown send. A charged effect remains charged and OutcomeUnknown. Retained native slots require a CleanupProof before retirement. Live recovery pins the original pidfd/cgroups; late recovery independently requires the original guardian reaped and both original cgroup names deleted from their original cgroup-v2 mount, and a complete whole-service process scan including zombies in deleted descendants. Replaced groups, unreadable identities and failed observations keep the claim. An empty private attempt list is useful only while holding that same account-wide lock; it cannot release a retained attempt. Recovery resumes the same run without unlocking and reacquiring between reconciliation and admission.

The before-COMMIT witness loses the final charge root acknowledgment, then exits without Drop cleanup. The after-COMMIT witness exits after observing the actual protocol child but before reading EXECUTING. A new host runs the real recovery executor and the real effect pump. Both retain one charge and start no replacement child. The unsafe recovery mutations actually execute a replacement protocol child before failing the named assertion.

WriterHost drop now synchronously revokes native lifetime before shutting down its router, including when a short-lived raw-usage callback still holds the owner. A Stop witness accepts a proved Retired result as well as Stopping because C3 publishes native completion.

Evidence and all raw logs are untracked under `target/s4b-c3/`. Cargo commands source FFmpeg, require at least 6 GiB available, use four build jobs and test threads, `flock -o`, niceness 10 (19 for mutations), a 580-second limit (120 for mutations), and worktree-local `LOCALAPPDATA` and short `TMPDIR=target/t3`. Nothing is pushed.

## C3b

`prepare_task_endpoint` now has explicit first-attempt, retained-actor continuation and durable-reopen paths. Later attempts require the original authority to be retired. Continuation drains and revokes only that authority, retains the registered Core and exact branch/checkpoint, and keeps the frozen result and original merge envelope. Reopen restores both the parent candidate and task from their sealed SpecialistBase records; it refuses a changed checkpoint or missing original history. Task authority is issued only after the new H1 task-history record is acknowledged.

The task-specific persistence path holds the existing registered Core fence and compares the complete published HistorySnapshot before reusing an unchanged checkpoint. This includes undo/redo stacks, batches and floor identity. Ordinary branch-save semantics are unchanged. Task freeze and close keep an already persisted checkpoint, so authority-only continuation cannot replace frozen merge identities. Native completion and real recovery checkpoint retained task actors before retiring reservations.

The host checkpoint, freeze and merge APIs use the existing H1 publisher. The original merge envelope is persisted before the merge side effect; retries and restarts use its original receipt. This is a host-level port for C4's MCP adapters, with no second actor or event pump.

Before reserving a new attempt, the same H1 update moves retired records into a bounded sealed archive. Original execution identities and native recovery references remain reachable. The three-record projection cap remains in force for retained attempts; eight successive reservations/recoveries prove that retirement frees capacity.

The history witness performs edits, Undo to create a task redo tail, authenticated turn exit, a new attempt, restart, merge, frozen continuation, another restart, original-receipt replay, then Stop and reopen. It compares entire task and manual HistorySnapshots with non-empty redo tails and compares the complete frozen history record, allowing only the attempt authority to change. It also closes the frozen task actor before continuation. The archive witness checks all eight original identities.

## C3 fix 1

Astra A1 now uses one root transaction. Registered task/candidate checkpoints are staged as immutable, pinned objects; H1 admission matches their exact history and base references, and the existing publisher installs the branch index and history together. The strict continuation binding comparison remains. Before the cut, only the previous acknowledged history is durable; after it, the complete new history is durable. Twelve real process-exit cuts cover staging and both sides of publication on checkpoint, freeze, native completion and recovery, with non-empty redo tails and exact manual history. An unknown root acknowledgment also reconciles the original cut without replacing its checkpoint. Standalone MCP fixtures explicitly use their fixture publisher because they have no H1 run.

Astra A2 carries the charge's remaining monotonic lifetime into COMMIT. Under the same host mutex as Stop, COMMIT refreshes durable wall/elapsed accounting, checks token and unresolved-usage limits while excluding only this charged send's future usage, then checks both clocks again before writing. Refusal closes startup, retains its charge and requires native cleanup proof. Barrier witnesses cover the six-hour deadline, monotonic expiry, late token exhaustion, missing usage and clock uncertainty.

Muse M1 adds a distinct unbound cleanup proof. It requires the nonce-scoped unit name absent across the cgroup-v2 tree and a complete `/proc` scan, including deleted descendants. Reserved H1 attempts without a native record recover only under that proof. Private retirement occurs before H1 reconciliation so a crash between them is the already-proved-clean, no-private-record case under the same account lock. Failed prepare paths use the same proof or the existing bound cleanup proof. The unbound crash witness preserves one charge and executes no replacement; four failed preparations at the reserve-to-bind boundary leave the machine slots usable. The guardian zombie witness also checks the new unit-name scan. Bound cleanup remains recoverable after its retired H1 attempt is archived.

Muse m2 refuses charging without an existing durable clock. m3 persists a fixed five-second rate-limit backoff, clears it through the pump only when due, including after attempt archival, and spends the elapsed time. m4 reconciles just-reserved attempts on profile, ceiling, charge or launch failures, while retaining charged/unknown effects, any unproved native claim and the exact history of an older retired actor.

Production pump construction/reopen wiring remains C4 (Muse m1). Per-profile usage adapters remain C6 (Muse m5); the current native reader uses Codex usage. These deferred findings were recorded, not implemented. Production registration remains empty.
