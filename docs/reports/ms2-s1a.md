- F3 `fa6d4436`: each escape attack reports its syscall result in a reply frame before anything is closed or dropped, then uses what it obtained and parks. `escape_native` collects every result in both modes before asserting. The design names the bound (`MS2-MEDIA-SANDBOX.md` 5 s initial probe, 250 ms grace, then "native emptiness and reap within a further 2 s"). - AppArmor hypotheses, profile unchanged: the profile is `flags=(unconfined)` with only `userns`, attached by path. (1) Any userns created by a process the profile does not attach to (a different helper path, a wrapper) falls under Ubuntu's restrictive unprivileged-userns handling; uid_map, mount or pivot_root then fail. Neither explains a silent hang by itself; the diagnostics should name the phase.
## Confirm-review test gaps (A, B)
- A `94d5659c`: `scripts/ms2_s1a_mutations.py` restores its source on SIGINT, SIGTERM and SIGHUP. Each cargo or test step runs in its own process group; on interruption the script checks that the group leader is the child it started (pgid and `/proc/<pid>/cmdline`), sends TERM then KILL to the group, reaps it, and waits until the group is gone. The restore runs with those signals blocked, then `git diff` on every audited file; a difference prints `MS2_MUTATIONS_RESTORE_FAILED` and exits 3. SIGKILL cannot be handled: the header says to check `git status` after a killed run, and the script refuses to start (`MS2_MUTATIONS_REFUSED`, exit 2) on a dirty audited file. Witness `scripts/ms2_s1a_mutations_selftest.py`: SIGTERM and SIGHUP during a long step leave every audited file byte-identical and clean against git, and the step group gone; red without the handlers (exit -15, file left mutated, group alive).
- B: each native pass asserts the mode it requested and never accepts the other. Primary needs a systemd user manager on the session bus the runtime uses (`busctl --user`, `tests/support/mode.rs`). When none answers, a primary pass prints `MS2_PRIMARY_UNAVAILABLE` or `MS2_NATIVE_NOT_RUN` and runs nothing in its place; when one answers, a degraded fallback fails the test. `MS2_MODES_RAN` lines are written past libtest's capture (`deadline::announce`); the slow tier also runs with `--show-output`.
  - `escape_native`: the control and all 12 attacks must report the requested mode (the primary-to-degraded tolerance is gone); a degraded primary control fails with a manager, otherwise skips the primary attacks with `MS2_PRIMARY_UNAVAILABLE`.
  - `runtime_native`: `automatic` must give primary when a manager answers, degraded otherwise; `degraded` must give degraded; the bus-disconnect test now checks the same bus and prints `MS2_NATIVE_NOT_RUN` under no-bus instead of failing.
  - `witness_native`: the primary loss tests already refused degraded (`MS2_LOSS_UNAVAILABLE`); they now fail when a manager answers. The silent-helper witness requests no mode and must run the mode the environment offers. The degraded loss tests already asserted degraded.
  - `rss_native`: degraded only, already asserted; unchanged. `apparmor_native`: no mode requested (the gate is about user namespaces); it now prints the mode it ran.
- Mutation run on the B tree: 8 kill/bound mutations and 4 escape removals red at their intended result; restored controls, bound controls and escape controls green (26 results, modes degraded and primary); source restored.
