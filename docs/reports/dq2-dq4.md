## Stage A — measured edges

Public surface: `SoundProfile::from_raw/from_hops`, `Hop`, `Word`, `Settings`, `Span`, prepared `Dialogue::{resolve,guard,sound_at,frame_edge}`, `CutRequest`, `ResolvedCut/ResolvedEdge`, `EdgePlacement`, `FramedEdge`, typed input/profile/edge refusals, and `pad_edge`. The prepared value owns one profile and its derived quiet/valley/gap/dip intervals; accessors borrow it. A refusal owns a word name so callers may keep the diagnostic after dropping the measurement.

Media contract: canonical non-overlapping 10,000-us hops on source time zero, explicit recording duration, shorter final hop. For the selected decoded audio stream, peak is the maximum absolute full-band sample over all channels in the hop; RMS is the maximum of per-channel sqrt(mean(sample squared)) in that hop. Never average channels before measuring. Convert amplitude by 20*log10 to signed hundredths of dBFS, round nearest, saturate to [-12000, 0]. Voice is true if any channel's VAD interval overlaps the half-open hop; do not derive it from ASR word times. The builder validates matching lengths, coverage, nonpositive levels and RMS <= peak, and saturates below the floor. The general constructor accepts 1..31000-us hops; the media producer must supply 10000 us. Words have positive, ordered source-microsecond spans within the recording; overlapping words are allowed with ordered ends. Source content hash, audio stream identity, provenance and cache binding belong to the later media layer, not this pure numeric type.

Scarlet differences and reasons:
- One complete finite recording profile replaces scan pages and alternate transcript arrays; missing evidence is a typed refusal, never an executable timing fallback or a planner review state.
- Digital recording endpoints are explicitly `SourceBoundary`, not claims of new measured quiet; a request with no quiet anywhere refuses.
- Integer centidB thresholds conservatively floor Scarlet's amplitude cutoffs. One Settings value owns all acoustic/timing policy, including 150/100-ms air, 120-ms snap, -55-dB dip and 100-ms in-word gap. Review adds a separate 50-ms dip reach and a 100-ms minimum word-removal duration.
- Untranscribed sound and a short valley above the dip cutoff refuse conservatively. A pause that already fits its requested leave time refuses before clamping through intervening sound.
- Fractional frame instants use exact rational arithmetic. Nearest rounding is clamped into measured support and re-guarded without truncating microseconds. Dip support includes adjacent equally deep hops inside the same word search window; the framed report gives the actual returned hop and signed rounding shift.
- No TypeScript timeline/planner staging/review or rendering is ported. Source test names accompany each ported case.

## Stage B — cut score

Stage A is `32877a1d`. The lead's `kinewright-agent::cut_score` home fits: the existing eval module runs sessions and `te1_eval` owns the paid usage experiment; this addition needs neither. Both the module and the new `kinewright-cut-score` binary require `eval-harness`. Existing transcript editing and pacing are unchanged.

API: strict JSON `Case`, `Candidate`, `SourceRange`, optional inclusive word-index `RequiredLine`; adjustable `ScoreSettings`/`Share`; `score(&Case, &Candidate, &ScoreSettings) -> Result<Score, CannotScore>`; `candidate_from_document(&Document, AssetId, TrackId) -> Result<Candidate, CannotScore>`. `Score` exposes removed-word/time PRF counts and exact ratios, edge matches/tolerances, missing required lines, playback pacing and a null `time_to_first_change_micros` (it needs a run trace).

Offline command (real case and candidate files stay outside the repository):
```sh
cargo run -p kinewright-agent --features eval-harness --bin kinewright-cut-score -- --case /outside/case.json --ranges /outside/candidate.json
# Or replace --ranges with:
# --project /outside/edit.kinewright --asset-id 1 --track-id 1
```
Run Cargo through the shared lock and FFmpeg setup as in the brief. The command prints `scored` JSON (exit 0), or refusal JSON (exit 2 for typed cannot-score; exit 1 for usage, read and parse failures). It reads local files only; no session, provider, credentials, network, audio decode or project write. Command tests score an actual saved project, compare its bytes afterwards and use a media path that does not exist.

Definitions and deliberate differences from Scarlet:
- One recording's complete duration is the base; its SHA-256 must match. Empty-text, zero-duration or unordered words are not repaired by sorting/filtering: invalid entries refuse so inclusive word indices cannot change. Source coverage is merged for word/time metrics, but playback order and repeated occurrences survive for edges and pacing. Interior source jumps at recording endpoints still count as edges; Scarlet's merged-source edge set can hide these.
- Harmless source-contiguous splits coalesce before word mapping, so a split through a word cannot truncate its played timing. All intervals use exact integer microseconds, without the floating epsilon. Word keep share is at least one half within one coalesced playback occurrence. Disjoint fragments cannot combine to retain a word; this corrects the earlier merged-coverage rule and the pacing midpoint rule. Ratios retain unreduced counts plus an integer-rounded three-decimal string; a zero denominator has a null display. Identical all-kept cuts have undefined removal PRF, rather than invented positives; `reference_equivalent` makes their equality explicit. There is no weighted aggregate.
- After review, tolerance counts use maximum-cardinality same-side source-order matching. The widest 1-s assignment first maximizes cardinality, then minimizes total absolute error, with deterministic ties. This intentionally replaces Scarlet's greedy nearest-first algorithm, which could reward worse edges. Defaults report 20/100 ms (the requested subset of Scarlet's 20/100/500 ms); settings may add tolerances. Error quantiles retain exact fractional microseconds rather than rounded decimal milliseconds.
- Automatic sentence requirements use the reference's >=80% word keep share and the candidate's >=50% cut share, both adjustable. Explicit required word-index lines are unconditional; overlapping missing lines use union duration. Punctuation and 1.5-s sentence breaks follow Scarlet.
- Pacing retains Scarlet's 500-ms gap, 1-s long gap, 250-ms beat, 3-s repeat window and 25-s phrase-search defaults. Reports keep exact microseconds rather than rounding seconds. Token comparison uses the standard library's Unicode alphanumeric classification instead of adding a Unicode-regex dependency for JS's Letter/Number categories; alphabetic combining marks can therefore normalize differently. Labels in brackets are excluded from pacing. No level classification or trace metric is invented from words alone.
- The Document adapter uses the chosen asset's content fingerprint, never the project digest, and requires an explicit dialogue track id. It refuses mixed sources, non-media clips, speed changes, selected-track mute/routing/processing, global processing or solo state that silences the selected track, enable automation, fades/transitions, gaps/overlaps, trailing program mismatch and inexact project-frame spans. Unrelated track mixing is allowed. The caller names the dialogue track; audio and video track kinds are both eligible. Source-frame endpoints round to nearest microsecond (<=0.5 us); an empty rounded span refuses. Other tracks are outside this selected-dialogue score, not whole-project acoustic proof. Invalid documents refuse before extraction.

## DQ2 and DQ4 review fixes

Astra's guard and score findings were reproduced in the source; the owner ruled their final behavior. The unsafe generic dip exception is gone. Guard order is recording boundary, trusted quiet, deepest overlapping word interior with a bounded dip exception, then the dip rule outside word interiors. `Settings::dip_reach_micros` defaults to 50,000 independently of kept slack. A 50-ms intrusion is allowed; 51 ms is refused. All overlapping word interiors must satisfy it. The resolver uses this reach on the kept side and checks its selected dip with the guard. `DipIntrusion { word, boundary, micros }` is fixed-size measurement, not permission; it is carried by every word-interior `LevelDip` placement. The public measurement query can also describe a refused instant. DQ3 will display it as a fourth independent warning.

The accepted closure fixture keeps its start at 255,000 us, 45,000 us before the end of word 0 (`cat`). A dip around 150,000 us inside a 400,000-us word now refuses in the guard, resolver and frame recheck. Frame ties preserve material, later for an outgoing edge and earlier for an incoming edge, pinned by `dialogue_frame_ties_keep_material_on_each_side`. Frame arithmetic remains exact at fractional rates; regression witnesses distinguish truncation and an inclusive dip endpoint. `minimum_word_cut_micros` defaults to 100,000 and returns typed `WordCutTooShort`; the two-frame floor and final framed-cut ordering/length checks belong to the tool that knows the frame grid. Quiet RMS uses -4001 centidBFS to keep round-nearest input quantization on the conservative side.

The matching fix deliberately differs from Scarlet. Each tolerance count is a linear walk over source-sorted edges per side. Widest-window error matching uses order-preserving dynamic programming, reconstructed with linear row storage rather than a quadratic traceback table. Candidate A in Astra's competing-neighbor example now matches 4/4 at 100 ms instead of 3/4, with 90-ms error, while candidate B's farther edges have 95-ms error. An exhaustive small-input oracle checks cardinality and total error. Word labels and pacing now both require half coverage in one joined playback occurrence, inclusive of either exact half; a tiny middle fragment or disjoint quarter fragments do not become a played word.

The offline command reads supported admission's borrowed inspection document, so current Studio saves are supported without the document-only writer restriction or a Document copy. The Studio command fixture snapshots every file before and after. Selected-track routing, processing, master/pan processing and solo exclusion refuse; unrelated track mix does not. Track kind is intentionally not restricted beyond Core document validation. Usage, read, parse and project-admission failures exit 1; only typed score refusals exit 2.

GLM F3 remains a deliberate difference. The input has one ordered word array, not a separate list of resolved repeated utterances inside a stretched word timing. The anchor therefore still scans the whole removed-word timing and can choose a different local dip; the new reach and guard constrain every accepted edge. Adding a second utterance representation is outside this pure input contract.
