# DQ2 measured edges and DQ4 cut score

## Stage A — measured edges

Base: `75b8dfae`; branch `dq2`. This is a pure Core addition: no caller, I/O, Document, rendering or existing transcript/pacing behavior changes. Scarlet `2cbab542` was read only; `LICENSES/scarlet-MIT.txt` is its unmodified MIT notice.

Public surface: `SoundProfile::from_raw/from_hops`, `Hop`, `Word`, `Settings`, `Span`, prepared `Dialogue::{resolve,guard,sound_at,frame_edge}`, `CutRequest`, `ResolvedCut/ResolvedEdge`, `EdgePlacement`, `FramedEdge`, typed input/profile/edge refusals, and `pad_edge`. The prepared value owns one profile and its derived quiet/valley/gap/dip intervals; accessors borrow it. A refusal owns a word name so callers may keep the diagnostic after dropping the measurement.

Media contract: canonical non-overlapping 10,000-us hops on source time zero, explicit recording duration, shorter final hop. For the selected decoded audio stream, peak is the maximum absolute full-band sample over all channels in the hop; RMS is the maximum of per-channel sqrt(mean(sample squared)) in that hop. Never average channels before measuring. Convert amplitude by 20*log10 to signed hundredths of dBFS, round nearest, saturate to [-12000, 0]. Voice is true if any channel's VAD interval overlaps the half-open hop; do not derive it from ASR word times. The builder validates matching lengths, coverage, nonpositive levels and RMS <= peak, and saturates below the floor. The general constructor accepts 1..31000-us hops; the media producer must supply 10000 us. Words have positive, ordered source-microsecond spans within the recording; overlapping words are allowed with ordered ends. Source content hash, audio stream identity, provenance and cache binding belong to the later media layer, not this pure numeric type.

Scarlet differences and reasons:
- One complete finite recording profile replaces scan pages and alternate transcript arrays; missing evidence is a typed refusal, never an executable timing fallback or a planner review state.
- Digital recording endpoints are explicitly `SourceBoundary`, not claims of new measured quiet; a request with no quiet anywhere refuses.
- Integer centidB thresholds conservatively floor Scarlet's amplitude cutoffs. One Settings value owns all acoustic/timing policy, including 150/100-ms air, 120-ms snap, -55-dB dip and 100-ms in-word gap.
- Untranscribed sound and a short valley above the dip cutoff refuse conservatively. A pause that already fits its requested leave time refuses before clamping through intervening sound.
- Fractional frame instants use exact rational arithmetic. Nearest rounding is clamped into measured support and re-guarded without truncating microseconds. Dip support includes adjacent equally deep hops inside the same word search window; the framed report gives the actual returned hop and signed rounding shift.
- No TypeScript timeline/planner staging/review or rendering is ported. Source test names accompany each ported case.

## Stage B — cut score

Stage A is `32877a1d`. The lead's `kinewright-agent::cut_score` home fits: the existing eval module runs sessions and `te1_eval` owns the paid usage experiment; this addition needs neither. Both the module and the new `kinewright-cut-score` binary require `eval-harness`. Existing transcript editing and pacing are unchanged.

API: strict JSON `Case`, `Candidate`, `SourceRange`, optional inclusive word-index `RequiredLine`; adjustable `ScoreSettings`/`Share`; `score(&Case, &Candidate, &ScoreSettings) -> Result<Score, CannotScore>`; `candidate_from_document(&Document, AssetId, TrackId) -> Result<Candidate, CannotScore>`. `Score` exposes removed-word/time PRF counts and exact ratios, edge matches/tolerances, missing required lines, playback pacing and a null `time_to_first_change_micros` (it needs a run trace).

Offline command (real case and candidate files stay outside the repository):
```sh
cargo run -p kinewright-agent --features eval-harness --bin kinewright-cut-score -- --case /outside/case.json --ranges /outside/candidate.json
# Or replace --ranges with:
# --project /outside/edit.kinewright --asset-id 1 --track-id 1
```
Run Cargo through the shared lock and FFmpeg setup as in the brief. The command prints `scored` JSON (exit 0), or typed `cannot_score` JSON (exit 2). It reads local files only; no session, provider, credentials, network, audio decode or project write. Command tests score an actual saved project, compare its bytes afterwards and use a media path that does not exist.

Definitions and deliberate differences from Scarlet:
- One recording's complete duration is the base; its SHA-256 must match. Empty-text, zero-duration or unordered words are not repaired by sorting/filtering: invalid entries refuse so inclusive word indices cannot change. Source coverage is merged for word/time metrics, but playback order and repeated occurrences survive for edges and pacing. Interior source jumps at recording endpoints still count as edges; Scarlet's merged-source edge set can hide these.
- Harmless source-contiguous splits coalesce before word mapping, so a split through a word cannot truncate its played timing. All intervals use exact integer microseconds, without the floating epsilon. Word keep share is at least one half, as in Scarlet. Ratios retain unreduced counts plus an integer-rounded three-decimal string; a zero denominator has a null display. Identical all-kept cuts have undefined removal PRF, rather than invented positives; `reference_equivalent` makes their equality explicit. There is no weighted aggregate.
- Edge matching is same-side, nearest-first, one-to-one within 1 s, with deterministic ties. Defaults report 20/100 ms (the requested subset of Scarlet's 20/100/500 ms); settings may add tolerances. Error quantiles retain exact fractional microseconds rather than rounded decimal milliseconds.
- Automatic sentence requirements use the reference's >=80% word keep share and the candidate's >=50% cut share, both adjustable. Explicit required word-index lines are unconditional; overlapping missing lines use union duration. Punctuation and 1.5-s sentence breaks follow Scarlet.
- Pacing retains Scarlet's 500-ms gap, 1-s long gap, 250-ms beat, 3-s repeat window and 25-s phrase-search defaults. Reports keep exact microseconds rather than rounding seconds. Token comparison uses the standard library's Unicode alphanumeric classification instead of adding a Unicode-regex dependency for JS's Letter/Number categories; alphabetic combining marks can therefore normalize differently. Labels in brackets are excluded from pacing. No level classification or trace metric is invented from words alone.
- The Document adapter uses the chosen asset's content fingerprint, never the project digest, and requires an explicit dialogue track id. It conservatively refuses mixed sources, non-media clips, speed changes, mute/routing/processing, enable automation, fades/transitions, gaps/overlaps, trailing program mismatch and inexact project-frame spans. Source-frame endpoints round to nearest microsecond (<=0.5 us); an empty rounded span refuses. Other tracks are outside this selected-dialogue score, not whole-project acoustic proof. Invalid documents refuse before extraction.
