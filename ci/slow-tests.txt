# Slow-tier manifest: the tests that run only with `--features slow-tests`.
#
# One test per line:  <test binary> <libtest test path> <source file> # linux/windows seconds
#
# - <test binary> is the executable's name without hash or extension: the crate
#   library (kinewright_media), an integration test (au3_fixtures, mcp_server)
#   or a binary crate (kinewright_app).
# - <libtest test path> is the name `cargo test` prints, and what `--exact` matches.
# - The seconds are the measured CI time at 4 test threads in green run
#   36377867892 (ubuntu-latest / windows-latest); they are the reason a test is
#   here, not part of the contract.
#
# Each test carries, right after its `#[test]`:
#   #[cfg_attr(not(feature = "slow-tests"), ignore = "slow tier: cargo test --features slow-tests")]
# `python3 scripts/slow_tests.py lint` fails CI if this file and those markers
# disagree in either direction; the fast job also checks that the tests it
# ignored with that reason are exactly these and that every other skipped test is in
# ci/ignored-tests.txt, and the slow job checks that it
# ran exactly these and that they passed.
#
# To add a slow test: mark it, add a line here, run the lint. To demote one to the
# fast tier: remove both. Never delete or weaken a test to make it fast.
#
# Kept in the fast tier on purpose, although each takes over 60 s or is near the line
# (review round C1-R1: coverage wins over the fast-time target):
#   cc7_fixtures::cc7_every_scenario_verifies_at_eight_bits / _at_ten_bits
