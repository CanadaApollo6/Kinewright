# Ignored-test allowlist: every test the fast tier may skip that is not in ci/slow-tests.txt.
#
# One test per line:
#   <test binary> <libtest test path> <source file> <os> <category>  # the ignore reason
# (the first three columns are those of ci/slow-tests.txt; a doctest uses the binary
# `doc-tests:<crate>` and the rustdoc name `<file> - <item> (line <n>)` as its path).
#
# os: where the test is ignored: `any`, `linux` or `windows`. Use `any` only if the test
#     is ignored on both; an ignore that is conditional on one OS gets that OS.
#
# Categories (a missing or unknown one fails the lint):
#   hardware       needs a physical GPU or an audio device; run on the NVIDIA lanes or by hand
#   on-demand      never meant to run in CI: manual performance measurements, live subscription
#                  runs, prepared-fixture builders, subprocess helpers
#   inherited-gap  a check that SHOULD run but is skipped for a pre-existing defect; needs a
#                  one-line reason after '#'; this is coverage debt, not a justification
#
# The authority is the compiled run, not the source text. `python3 scripts/slow_tests.py fast`
# (verify-fast) runs on each OS and requires the run to have skipped exactly the manifest plus
# the entries that apply to that OS, each reported `ignored` under its exact binary and test
# path (doctests included), and nothing else. An entry the run does not report as ignored
# (stale, misnamed, fabricated, or ignored only on the other OS) fails with "allowlisted but
# not observed as ignored on <os>"; a skip that is not listed fails as an unexpected skip.
# `python3 scripts/slow_tests.py lint` only checks the format, the category, the os and the
# inherited-gap reason, and that the source file exists: a cheap early check.
# To add an ignored test: fix the test, or add it here with an os, a category and a reason
# a reviewer accepts.
#
# Source: the ignored tests of green CI run 36377867892 (identical on Linux and Windows),
# plus the two on-demand software-renderer performance-evidence tests.
