FFmpeg
------

This installer bundles the shared DLLs from the pinned FFmpeg 8.0.1-r3 x64
Windows GPL build published by System233. This GPL-enabled build is used
deliberately because OpenReel is GPLv3 software.

Exact binary build and build-provider source:
https://github.com/System233/ffmpeg-msvc-prebuilt/releases/tag/ffmpeg-8.0.1-r3
https://github.com/System233/ffmpeg-msvc-prebuilt

FFmpeg upstream source and licensing information:
https://ffmpeg.org/download.html#get-sources
https://ffmpeg.org/legal.html

The FFmpeg license text shipped by the pinned build is installed beside this
file as FFmpeg-GPL.txt. FFmpeg is a trademark of Fabrice Bellard, originator of
the FFmpeg project.
